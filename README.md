### Средний уровень сложности

Добавлено 3 файла .py с решением заданий из индивидуального варианта.



**book.py** соответствует заданию 1 — класс Книга. Реализованы атрибуты название и автор, метод для строкового представления объекта класса. Приведён пример работы с классом.



**bank\_account.py** соответствует заданию 3 — класс Банковский счёт. Реализованы строковое представление, пополнение и снятие денег со счёта, проверки корректности действий с вызовом подробно описанных ошибок. Атрибут баланс защищён от изменений извне при помощи декоратора @property.



**animal.py** соответствует заданию 5 — наследование класса Собака от класса Животное. В родительском классе объявлен рабочий метод, который далее переопределён в дочернем. Объекты для тестового запуска хранятся в списке.



### Повышенный уровень сложности

Добавлено 2 файла .py с решением заданий повышенной сложности.



**singleton.py** — задание 1, паттерн Singleton — класс, у которого гарантированно один экземпляр на весь код. Реализован через переопределение \_\_new\_\_: при повторном вызове возвращается уже созданный объект. Классовое поле \_instance хранит единственный экземпляр.



**strategy.py** — задание 4, паттерн Strategy для расчёта цены. Абстрактный класс PriceStrategy задаёт интерфейс метода calculate, заданы три стратегии на выбор, реализующие различные процессы. Контекст PriceCalculator хранит текущую стратегию и позволяет менять её в процессе выполнения.



Подробные пояснения к работе алгоритмов представлены в коде.



Решения заданий не требуют установки дополнительных библиотек.
